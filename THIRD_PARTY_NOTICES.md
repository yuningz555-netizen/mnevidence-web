# Third-party dependencies

Frontend: React 18.3.1 and React DOM 18.3.1 (MIT), Scheduler (MIT), Lucide React (ISC), and GSAP 3.12.5 / ScrollTrigger (GreenSock standard no-charge license, https://gsap.com/standard-license/). Applicable installed-package license notices are included in `runtime.zip` under `third_party`. GSAP package metadata and its distribution notice identify the applicable upstream license. The interface does not redistribute paid GSAP plugins.

Backend: Flask (BSD-3-Clause), NumPy (BSD-3-Clause), pandas (BSD-3-Clause), scikit-learn (BSD-3-Clause), XGBoost / xgboost-cpu (Apache-2.0), pymoo (Apache-2.0), joblib (BSD-3-Clause), threadpoolctl (BSD-3-Clause), and Waitress (ZPL-2.1). They are installed from their official PyPI packages; those distributions carry their own notices.

Frontend build tools are Vite and the React plugin. They are development dependencies, not a requirement for running the prebuilt production site. Images already supplied with the local companion are included unchanged; no literature PDF figure is included in the public runtime.
